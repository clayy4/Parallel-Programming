## Цель работы

Доработать программу из первой лабораторной работы так, чтобы умножение матриц выполнялось параллельно с помощью **OpenMP**. Провести эксперименты с разным количеством потоков и разными размерами матриц и посмотреть, как ускоряется программа.

---

## Описание файлов проекта

- **matrix_generator.py** — создаёт случайные матрицы и сохраняет их в файлы.
- **main.cpp** — основная программа. Выполняет умножение матриц с OpenMP и автоматически запускает все эксперименты.
- **verification.py** — проверяет, правильно ли программа умножила матрицы.
- **benchmark.py** — строит графики по результатам экспериментов.
- **src/measurements.txt** — файл с результатами замеров времени.

---

## Проведённые эксперименты

Эксперименты проводились для матриц размеров:  
**200 × 200, 400 × 400, 800 × 800, 1200 × 1200, 1600 × 1600, 2000 × 2000**

Для каждого размера тестировалось **4 варианта** количества потоков: **1, 2, 4, 8**.  
Каждый тест запускался **3 раза**, и бралось среднее время.
Замеры призводились на Ryzen 7 5700x

## Анализ результатов

- Программа стала работать заметно быстрее при использовании нескольких потоков.
- Чем больше размер матрицы, тем лучше работает параллелизация.
- Самое хорошее ускорение получилось на матрице 2000×2000 — почти в 8.3 раза быстрее, чем с одним потоком.
- На маленьких матрицах (200×200) ускорение меньше, потому что накладной расход от создания потоков довольно большой.
---

## Вывод

В лабораторной работе я успешно добавил поддержку OpenMP в программу умножения матриц. 

Эксперименты показали, что OpenMP хорошо ускоряет задачу, особенно при больших размерах матриц. Автоматический запуск всех тестов внутри `main.cpp` сделал проведение экспериментов удобным.

В будущем можно ещё сильнее ускорить программу, если перейти на одномерные массивы для хранения матриц.
