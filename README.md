### 1. Цель работы  
Исследовать масштабируемость параллельной программы умножения квадратных матриц с использованием технологии **MPI** при запуске на высокопроизводительном вычислительном кластере **«Сергей Павлович Королёв»**. Оценить влияние количества вычислительных процессов (ядер) на время выполнения и выявить накладные расходы параллелизации.  

---

### 2. Краткое описание решения задачи  
Реализовано параллельное умножение матриц на языке C++ с применением библиотеки MPI. В основе алгоритма лежит построчное разбиение результирующей матрицы между процессами:

1. **Инициализация:** На процессе с рангом `0` выполняется генерация входных матриц с помощью Python-скрипта и их чтение из файлов.  
2. **Распределение нагрузки:** Матрица распределяется между процессами по строкам с учетом остатка: если число строк не делится нацело на количество процессов, первые процессы получают на одну строку больше.  
3. **Вычисления и сборка:** Каждый процесс вычисляет свою часть строк результирующей матрицы. Частичные результаты собираются на процессе `0` с помощью `MPI_Gatherv`, после чего формируется итоговая матрица.

### 6. Вывод  

- **Влияние количества процессов:** Конфигурация с максимальным количеством потоков (16 процессов) показала наилучшую производительность на больших структурах данных. Для матрицы размером 2000×2000 время сократилось до 921 мс по сравнению с 10314 мс у последовательной версии, обеспечив реальное ускорение примерно в 11.2 раз.  
- **Накладные расходы (Overhead):** На малых размерностях матриц (≤ 400) эффект от добавления новых процессов практически незаметен. Это связано с тем, что временные затраты на инициализацию MPI-среды, синхронизацию вычислительных узлов и межпроцессное распределение данных полностью перекрывают саму полезную вычислительную нагрузку.  
- **Характер масштабирования:** Начиная с размера 800×800, вычисления начинают доминировать над коммуникационными издержками, демонстрируя стабильное ускорение при масштабировании пула ядер. Рост времени вычислений с увеличением размерности $N$ подчиняется кубической сложности алгоритма $O(N^3)$. Параллельное умножение на MPI доказало свою высокую эффективность для ресурсоемких научно-технических расчетов.
